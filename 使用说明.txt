      MyDesk 个人行情工作台（Windows 本地版）- 使用说明
═══════════════════════════════════════════════════════════

【一、这是什么】

  一个运行在你自己电脑上的个人行情工具：深色界面、单机使用、
  无需注册登录、没有任何订阅或次数限制。

  * A股行情/资金数据由【本机直连】腾讯、东方财富公开接口
    获取（不经过云端中转），可能有延迟；黄金/加密货币等
    非A股品种仍为本机演示数据；
  * AI 分析 / 智能助手调用你自己配置的模型接口
    （OpenAI / Claude / Gemini / DeepSeek / Moonshot /
    OpenRouter / Ollama / 中转地址均可），API Key 只保存在
    你本机浏览器里，请求经本地代理转发，不落库、不进日志；
  * 自选、追踪、历史、对话等全部数据保存在本机浏览器。


【二、三步启动】

  第 1 步：解压本压缩包（右键 → 全部解压缩）
  第 2 步：双击文件夹里的「启动.bat」
  第 3 步：浏览器自动打开 http://localhost:3000

  ※ 窗口里依次显示 [1/4] ~ [4/4]：
      [1/4] 首次会自动安装依赖（国内镜像，约 3~8 分钟，只此一次）
            屏幕滚动大量英文属正常现象，不是卡死，不要关窗口
      [2/4] 初始化数据库客户端（约 10 秒）
      [3/4] 启动服务，看到 Ready / Local: 即成功
      [4/4] 浏览器自动打开 http://localhost:3000
  ※ 以后再启动会跳过前两步，几秒即可打开。


【三、功能一览（8 个菜单）】

  1. 总览        自选行情卡片、刷新倒计时、常用入口
  2. 数据看板    板块资金流向榜（实时/历史/行业/概念/地域 ×
                 流入/流出）、行点击联动明细、资金气泡图
  3. AI 分析     K 线图（8 档周期）+ 算法支撑/阻力/趋势通道 +
                 「开始分析」输出结构解读 / 关键价位 / 思路参考 /
                 风险提示，一键加入追踪；右侧智能助手随问随答
  4. 追踪        交易计划（方向/入场/止损/目标），可标记触达
  5. 历史        AI 分析存档
  6. 智能助手    多会话 AI 对话，按「结构/关键位/思路/风险」
                 的分析师风格回答品种问题
  7. 扩展        TradingView 浏览器扩展：图表页一键把品种
                 发回工作台（装法见第六条）
  8. 设置        AI 接口配置与测试连接、MCP 服务器管理、
                 刷新周期


【四、AI 功能怎么用】

  看板、行情、追踪等界面功能【不需要任何 Key】，解压即可用。

  「AI 分析 / 智能助手」需要一个大模型接口：
    → 设置 → AI 接口 → 点选服务商（自动填地址和模型）
    → 填你的 API Key（OpenRouter 有免费模型；
      本机装 Ollama 可完全离线免费）
    → 点「测试连接」变绿即可使用


【五、MCP（模型上下文协议）】

  位置：设置 → MCP 服务器
    · 手动添加或 JSON 导入（格式参考 data/mcp-config.json）
    · 启动 / 停止 / 工具发现 / 工具调用，trust 门控
    · 包内附演示服务器 scripts/mcp/demo_market.py
      （纯标准库实现，可作为你自己服务器的模板）


【六、浏览器扩展安装】

  Chrome：地址栏输入 chrome://extensions → 打开右上角
  「开发者模式」→「加载已解压的扩展程序」→ 选择包内
  public\mydesk-extension 文件夹（Edge 同理 edge://extensions）
  然后在扩展弹窗里填入 MyDesk 扩展页显示的回传地址与配对码。


【七、常见问题】

  Q：双击「启动.bat」黑窗口一闪就没？
  A：多是被杀毒软件拦截，右键 → 使用管理员方式运行再试。

  Q：窗口里全是乱码？
  A：旧版包遗留问题，本版已用 UTF-8 输出；如仍乱码，
     重新解压一次本包。

  Q：提示端口 3000 被占用？
  A：任务管理器结束占用进程，或重启电脑后再启动。

  Q：数据会丢吗？
  A：自选/追踪/历史/AI 配置都存在本机浏览器里，
     清浏览器缓存前请留意。

  Q：想停止程序？
  A：直接关闭「启动.bat」的黑色窗口。

  Q：启动卡住 10 分钟以上？
  A：1) 杀毒软件拦截 → 管理员运行或临时关闭杀软；
     2) 网络拦截 npm 镜像 → 换手机热点试一次；
     3) node_modules 半残 → 删除该文件夹后重新启动；
     4) 都不行 → 把启动窗口内容截图发给帮你装机的
        技术支持核对报错。
