# 上涨概率模型（逻辑回归 + 排除法）

离线验证模块，不动线上。LLM 退到讲理由/复核，不再是概率本身。

## 概率定义

`P(次日收盘涨跌跑赢上证)`。与胜率口径（跑赢上证）一致。

## 特征（9 个，全部时点值）

| 组 | 特征 | 说明 |
|---|---|---|
| 避开类 | relVolume | log1p(当日成交量 / 近 60 日平均成交量)，换手率代理（float-free） |
| 避开类 | amplitude | (high - low) / 昨收 |
| 避开类 | atrPct | 20 日平均真实波幅 / 收盘价 |
| 避开类 | ma20Bias | 收盘 / MA20 - 1，截断 ±0.3 |
| 避开类 | ma60Bias | 收盘 / MA60 - 1，截断 ±0.3 |
| 避开类 | limitUp20d | 近 20 日涨停次数（含当日），阈值与 limitRatio 一致 |
| 正向类 | gap | (开盘 - 昨收) / 昨收 |
| 正向类 | vwapBias | (收盘 - 当日 VWAP) / VWAP，VWAP = amount / volume |
| 板块先验 | sectorPrior | 板块资金流向代理（板块中位量比 + 板块中位 20 日收益，双排名平均） |

全部特征经截面 rank 标准化到 [-1, 1] 后进入逻辑回归。

**换手率口径说明**：这里用“量比代理”，不是 tickflow 的 volume / 时点流通股本。
DB 没有时点流通股本，用最新流通股本算历史换手会引入未来信息（lookahead），
所以用 float-free 代理，并明确标注。tickflow 换手 IC -0.066 是参考，不是同一定义。

**政策/美联储**：回测期无历史政策标签，`policyHit=0`、`fedEase=0.5`（中性），
`sectorPrior = 资金流向代理`。绝不编政策标签。实盘时 `blendSectorPrior` 按
`0.7 * 资金流向 + 0.2 * 政策命中 + 0.1 * 美联储宽松` 合成（权重是先验设定，不是拟合值）。

## 排除法（变体 d）

换手分位前 20% / 振幅分位前 20% / MA20 乖离 > +0.30，任一命中即排除。
**注意**：按全市场分位排，layer1 池（本身就是突破/反弹票）会被排空
（回测里 4 天零票）。全市场分位排除与突破型候选池不兼容——
如要用排除法，应改成池内相对分位或放宽阈值（下一步，不在本轮结论内）。

## 滚动回测结果（15 个决策日，2026-09-16~10-14）

| 口径 | T+1 平均净 | T+1 胜率 | 5 日平均净 | 5 日胜率 |
|---|---|---|---|---|
| (a) 旧流程 top-10 | -1.00% (n=76) | 38.2% | -2.59% (n=53) | 39.6% |
| (b) 旧流程前 5 | -1.22% (n=66) | 39.4% | -2.86% (n=47) | 40.4% |
| (c) 逻辑回归 top-5 | **-0.04% (n=75)** | **42.7%** | **+0.82% (n=55)** | **54.5%** |
| (d) 逻辑回归 + 排除法 top-5 | -0.34% (n=44) | 38.6% | -0.86% (n=27) | 51.9% |

逐日胜出：(c) T+1 赢 (a) 9/15 天，5 日赢 (a) 10/11 天。不是某一天带飞。

**如实说**：(c) 比旧流程好，但不是“稳赚”——(c) T+1 中位数 -0.55%、
5 日中位数 -0.53%，正收益占比约 45%；平均数是被右尾大赢家拉上去的。
校准：T+1 平均预测概率 0.468，实际胜率 0.427（略高估，基本靠谱）；
组内排序（谁排第一 vs 第五）在 T+1 上没有显示区分度（三分位胜率 40%/48%/40%，噪音水平）——
模型能选出较好的“一组”，但组内排序不可靠。

## 系数（全样本重拟合，仅供形状参考）

截距 -0.1735；relVolume -0.0374；amplitude -0.0730；atrPct +0.0148；
ma20Bias +0.0656；ma60Bias -0.0040；limitUp20d -0.0057；gap +0.0698；
vwapBias -0.1058；sectorPrior -0.0160。n=767,279，正样本率 0.4569。

**系数与单因子 IC 符号不一致的地方**（多变量条件效应，不是单变量效应，
特征间相关，不要单拎一个系数做因果解读）：
- vwapBias：单因子 IC +0.018（正），拟合系数 -0.1058（负）。已排除两个解释：
  公式无错（抽查茅台 2026-10-15：收 1312.97，VWAP 1306.88，合理）；
  与 gap 的相关系数约 0（-0.016），不是被 gap 带偏的。更可能的解释：
  单因子 IC +0.018 本身在噪音水平内（约 240 天，标准误约 0.065），
  加上标签不同（二值“跑赢上证”vs 连续收益率）与样本口径不同，弱因子的符号翻转并不意外。
  不要把“盘中强势均值回归”当定论——它只是条件效应的一种可能解读，需更多数据验证。
- ma20Bias：单因子 IC -0.030（负），拟合系数 +0.0656（正）。
  条件效应解读：控制波动后，温和站上 MA20（健康趋势）是正信号；单变量的负 IC
  被极端乖离 + 高波动带偏了（乖离已截断、波动已控制）。
- atrPct / limitUp20d 系数接近 0：其单变量效应被 amplitude / relVolume 吸收了
  （amplitude 与 ATR 的截面相关系数约 0.62，波动率这对特征共线性强）。

## 局限（必须写清）

- 样本小：只有 15 个决策日；训练窗口约 1 年，且偏下跌/均值回归市。
- 滚动回测是样本外（每折训练只用 D-2 之前的数据），但 15 天与旧流程开发用的是同一批天，
  有轻微选择偏差。
- 5 日评估只覆盖 11 天（后 4 天 T+6 超出数据范围）。
- 财务因子未进模型（tickflow 本地 financials 为空，未评估）。
- 政策/美联储特征回测期恒为中性，未验证其增量作用。
- 系数需定期重拟合；市场风格切换后可能失效。
