## 二、你问的 5 个问题，逐条回答

### Q1：AI 对话四模式的骨架、八大条件会不会随模式变？选日期后会不会考虑持股日期？

**骨架**：四个模式里**只有「决策模式」有完整结构化骨架**（`MODE_NOTES.decision` 多字段模板），研判/深度/搜索只有一句话口径。这是 P17 有意定的——四处都挂模板会口径漂移。
**八大条件卡**：**不随模式变**。反过来是「每张卡自带一个模式」，点卡时才切模式，卡本身是固定的。
**持股日期**：**目前不考虑**。AI 对话里没有日期选择器，也没有「持股日期/建仓日」输入项；成本卡只收**成本价 + 仓位**，周期（horizon）会注入系统提示词。所以「我 9/10 买的，现在怎么看」这类问法，模型拿不到建仓日。

> 要不要补？可以加一个「建仓日期」输入 → 注入 prompt（成本价旁边），改动不大。预留，等你点头。

### Q2：稳智的市场环境理由/新闻怎么来的？

逆推它 `inference.reason` 的构成：**最近 4 个交易日的市场宽度序列**（MA5 上方占比逐日）+ **当日情绪读数**（下跌家数 / 跌破 MA3 / 跌破 MA5）+ **涨停/跌停/最高连板（含近期极值对照）** + **当日指数表现（上证/深成/创业板 + 日内形态）**，由 LLM 写成一段话。新闻走 7x24 快讯按主题关键词命中。
**本地已照此实现**（`market-inference.ts`），覆盖 2026-04-20 ~ 2026-09-24 共 110 个交易日。实测：

```
date=2026-09-24 → 退潮反抽 / 退潮 / 置信 0.66
date=2026-09-21 → 强势上行 / 主升 / 置信 0.80，含 09-16→09-21 四日 MA5 占比 40.29→52.03→72.84→89.52
```

唯一差异：稳智理由里带**3 日成交额序列**，本地种子没这个字段——不编，理由里就不写成交额。

### Q3：日期为什么不跟着交易日走？

**根因不在前端**：服务端 `/api/market/trade-date` 一直是对的（today=09-28 / tradeDate=09-24 / isTradingToday=false，走行情源日K，节假日自动识别、不误伤正常开盘日）。问题在三处：
1. LLM 分析的主题热度日期**硬编码 `2026-09-24`**；
2. 大盘趋势区间的结束日期用 `new Date()`；
3. **涨停池把 trade_date 写成系统当天**（09-24 的涨停名单挂在 09-28 底下）——这是最像假数据的那处。

三处全修。现在口径统一为：**行情源认的最近交易日；当天开盘就是当天，休市就停在上一交易日**。

### Q4：个股画像默认展开 —— 已改默认收起。

### Q5：五档盘口为什么 AI 分析里永远没有？

**根因**：`stock_depth` 只在「模型自取」清单里，**从来没进自动调度预取表**（`skills-core.ts` 原注释：怕 tdx 冷启动 4s 拖慢）。实测模型一次都不会自己调 → 数据侧有五档，AI 输出里永远没有。
**已改**：个股分析预取从四件套升**六件套**（快照 / 盘口 / 逐笔 / 日K / 资金流 / 个股消息），盘口与逐笔标为非 required（网关没起就留 missing，不拖住一轮）。同时在提示词加了第 8 条纪律：**必须读懂再写，禁止原样罗列档位**——要说委买卖比压在哪侧、卖一大单是真压力还是托单、档位稀疏说明承接薄；休市时说明它只是收盘快照。

## 四、与稳智逐菜单对比：谁更真？

| **奇门/订阅/admin** | 计费/付费/后台 | 排除项 | — |

### 谁的数据有假？

**本地没有假数据**——这是我这轮扫下来最确定的一条。判据有三：
1. 所有缺源都走 `missing` 数组显式登记（主力净额 0 家、广度无沉淀、北向不披露、成交额/持续天数无字段）；
2. `demo-provider` 存在但**只在用户显式选「演示数据」时启用**，且注入模型的每段都带 `DEMO` 标记，AI 被明令不得当行情引用；
3. 上游故障时**报错不兜底**（`quotes-all` 就是例子）。

**稳智侧我看不到的**：它 `/api/review-stats` 那张日频表是它自己收盘后算的，我无法验证其对错。有一处值得警惕——它字段名写「沪深成交额_**万亿**美元」而实际是万亿元，这种命名粗心说明它的字段层不严谨，但数值本身无证据有问题。

### 还能再参考什么（按性价比排序）

1. **涨跌停板历史分布 + 连板梯队历史**（稳智 `/home` 两块图）——本地只有当日。缺的不是算法，是**每日收盘沉淀**。把 `stock_daily_close` 的调度器跑起来，这两块和图都能真算出来。
2. **5 日线占比的分组序列**（微/中/大盘三条虚线）——同上，靠沉淀。
3. **12 指数可切换**（本地只有 3 条）——东财指数K线能直接扩，纯搬砖。
4. **因子面**（缠论/高斯通道/VWAP/竞价弱转强/吸筹/庄家）——公式确定性、无缺源，但工程量大，建议分批。
5. **复盘统计回填引擎**（S2）——稳智的历史能回看是因为它有完整日频表。本地 110 天种子只到 09-24，之后靠回填续写。这是所有「历史回看」需求的共同前置。

**共同结论**：差距**不在算法、不在数据源，全在「每日收盘沉淀 + 历史回填」这一件工程**。稳智是「收盘后预计算入库」，本地是「实时取数 + 部署日起攒数」。把沉淀跑起来，上面 1/2/5 三项会一起解决。
