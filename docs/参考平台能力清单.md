# 参考平台能力清单

> 本文汇总一款面向 A 股的同类型个人量化 / 分析工作台（Web 产品）对外可见的能力，按**数据维度**与 **UI 维度**两类整理，作为本仓库功能建设的对照基线。
> 来源：该产品的生产前端构建产物逆向、登录实机抓取渲染态与网络请求、以及其公开页面截图。仅记录有硬证据的部分；扒取不到的实现细节不在本文杜撰。

---

## 一、产品概览

- **形态**：Web 应用（Vue 3 + Element Plus，构建器 rolldown）。AI 对话是独立产品线，相关代码外链到 CDN，与行情 / 自选等原生业务解耦。
- **一级菜单（9 项，纯一级平铺，无二级展开）**：
  1. 大盘情绪
  2. 量化因子选股
  3. 行业
  4. 行情
  5. 自选
  6. LLM 分析（独立入口）
  7. AI 对话（独立入口，与 LLM 分析并列）
  8. 奇门遁甲
  9. 订阅账号与点数（商业化入口）
- **全局壳**：深黑 / 白天双主题（localStorage `theme`，无闪屏内联脚本）；侧栏 9 项平铺 + 底部「最近」会话区 + 收起按钮；登录态；全局错误边界与错误文案映射。

## 二、大盘情绪

- **顶四卡**：情绪温度 + 仪表盘 / 成交额 + 较昨日 / 连板高度 + 涨停跌停三四五板 / 涨跌比 + 跌家数·低 5 日·低 3 日。
- **成交额趋势**：蓝柱 + 黄色平滑线（单位「万亿元」）。
- **5 日线占比趋势**：整体实线 + 微盘 / 中盘 / 大盘三条虚线（四序列，0–100%）。
- **涨跌停板分布对比**：历史逐日对比图。
- **连板梯队结构**：历史逐日梯队。
- **指数涨跌幅**：12 指数可切换（上证 / 深成 / 创业板 / 中证 1000 / 全 A / 红利 / 小盘 / 创新 / 中小盘 / 小盘高贝 / 红利 100 / 国证 A 指）。
- **控件**：日期段 + 行情状态下拉（震荡 / 牛市 / 熊市）+ 蓝色主按钮。
- **数据底座**：由一张日频宽口径表 `/api/review-stats`（每天一条）驱动全部图表与四卡。

## 三、量化因子选股

- **多因子模型**：字段目录 + 操作符条件构造；近 N 日涨跌幅窗口（2–250 日 / 满足 K 天）。
- **因子面（维度极宽）**：站上 MA5/10/20/60/90/144、吸筹 / 强势吸筹 / 庄家控盘、RPS（个股 / 板块 / 行业）、支撑压力线、缠论（顶底分型 / 三买三卖 / 中枢 / 突破）、江恩支撑、VWAP（日滚动 / 全历史）、高斯通道（中上下轨 / 拐头 / 起航 / 超买）、竞价弱转强、超级共振、主力攻击 / 触发。
- **策略社区**：策略保存 / 分享 / 点赞点踩。
- **候选池冻结 → Agent 优选 → 次日验证**：冻结时点快照 + 「请从量化候选池中自主研究并优选…给出入选理由 / 入场条件 / 仓位节奏 / 失效条件 / 主要风险」的 Agent 提示词；入选后自动创建记录，等待下一交易日验证（`/api/qf/forward-returns`）。
- **呈现**：默认 12 列（含行业 / K 线形态 / 趋势压力线）；5152 全量靠盘后预计算。

## 七、LLM 分析 + AI 对话（双入口）

### 7.1 空态

- Hero 标题「向参考平台 AI 提问」+ 输入框。
- 输入框**内嵌**模式选择器：决策 / 研判（互斥）+ 深度思考 / 实时搜索（两个独立开关）+ 搜索状态指示灯。
- 图片上传按钮（accept：jpeg / png / gif / webp）。
- 推荐问句卡：2 张展开 + 「展开更多 6 条」，共 8 条。

### 7.2 对话中（AI 对话）

- **Agent Loop 六步时间线**：理解问题 → 选择分析方法 → 获取行情与市场数据 → 核查新闻与公开信息 → 综合分析 → 生成结论。
  - 状态图标：✓ 已完成 / ● 进行中 / ○ 等待中 / ⚠ 失败；耗时格式化中文单位；可折叠展开。
- **研究卡片（11 字段决策卡）**：
  - 🎯 研究结论 · 📌 核心结论 · 📌 依据 · 📈 关键信号 · 📊 强弱量价 · 🧪 反证状态 · 🗓️ 触发条件 · 🛑 失效条件 · 📦 仓位节奏 · ⚠️ 风险提示 · 🧭 操作参考
  - 「反证状态」固定一格写「什么情况说明我错了」，是方法论标签而非可选项。
- **结构化结论契约**：回答 markdown 段落名（核心判断 / 板块概念焦点 / 最终关注清单）→ 前端正则切 JSON 对象；关注清单项格式 `名称 (代码) | 标签 | 标签`，最多 8 条。
- 分析数据表、引用来源条（按域名分组，每条带外链）。
- 「深度思考中 / 快速分析中」过程状态。

### 7.3 事件流协议

- 事件名：`stage` / `step` / `agent_started` / `answer_started` / `answer_finished` / `answer_chunk` / `ping`（心跳）/ `block_started` / `block_finished` / `channel`（flow | reasoning | answer 三通道）。
- **任务式而非裸 SSE**：`POST /api/ai-agent/tasks` 建任务拿 task_id → `GET /api/ai-agent/stream/{id}?last_event_id=N` 断线续传（重连带最后事件序号补发）。
- 连接异常有四级降级文案（轮询 / 后台同步 / 补齐快照 / 核对状态），全部带 `request_id`。
- 最终以服务端落库的 `canonical_markdown` 为准（流式只是过程）。

### 7.4 意图 / Prompt 结构

- 后端意图路由：12 个模板 × 5 个交易周期 = 60 种组合，按意图选 1 个模板（模板在服务端拼装，前端只提交控制参数）。
- **七维分析框架**：市场环境 15% · 产业逻辑 20% · 基本面 20% · 资金行为 20% · 技术面 20% · 综合判断 5%；末维必须给出可执行的入局计划。
- **预设问句库**（8 张卡片 + 参数化模板）：七维分析 / 按成本制定持仓计划 / 判断能否买入 / 多股对比 / 板块当前阶段 / 今日仓位策略 / 筛选持续流入板块 / 制定交易计划。
- **交易周期**：5 档（超短 1–2 天 / 短线 3–5 天 / 短中 / 中线 1–2 月 / 长）；自动检测（`resolveTradingHorizonForInput` 正则）+ 未命中弹窗拦截；跨会话记忆。
- **多模态**：图片上传，payload `images[]`，前端不压缩直传，服务端决定用哪个多模态模型。

### 7.5 状态持久化

- `active_task` 恢复：刷新页面后继续接收流式回答（task_id 持久化）。
- 任务过期时间 15 分钟（`9e5`）。
- 多环境隔离（存储 key 加 `:storageScope` 后缀）。

### 7.6 错误人话化

- 结构化错误码（下划线蛇形）+ 人话映射表，例如：`task_in_progress` → 「上一条消息仍在分析中，请稍候再发送」；`points_insufficient` → 「点数不足，请先充值」；`wallet_unavailable` → 「钱包当前不可用，请稍后重试或联系管理员」；`billing_freeze_failed` → 「发送前校验点数失败，请稍后重试」；`login_failed` → 跳登录页。

### 7.7 LLM 分析五 Tab 研究工作台

1. **主题热点**：行业 / 概念双 Tab + 日期；主题卡（热度 / 趋势 / 3 日资金）；点主题 → 市场环境长文卡（由日频表数据模板生成）+ 策略结论 + 标准化映射明细 + 该主题个股汇总。
2. **研究池**：筛选器矩阵 + 收盘态横幅 + 表格（代码 / 来源标签 / 策略 / 阶段 Entry·Watch / 仓位 / 置信度 / 买点价区间 / 关注）。
3. **板块全景看板**：板块 / 概念全景表（1/3/5/7 日涨跌、资金流、Top100 占比、MA20 占比、集中度）。
4. **个股评估矩阵**：个股多维评估（当日 / 5 日资金、收盘 / 早盘、≥5/90/144 日线、流通市值、涨跌）。
5. **产业链研报分析**：产业链结构 + 研报式结论。

### 7.8 题材热度面板（「一屏看全」的本质）

- **不是独立页面**，而是 AI 回答里一段结构化输出被前端渲染成 dashboard：顶部 5 个「Tab」实为 `suggested_queries` 追问胶囊；中间卡片墙是 `presentation_meta.sections`（每段含 `icon / title / tone / status / content`）；底部「最终关注清单」是可点击股票卡。
- 数据源：`theme_heat_all_in_one` 是后端喂给模型的一个大数据块（字段变化不影响前端，前端只按行解析成 judgement / themes / watchlist 三分类）。
- 视觉：深色卡片 + 数字高亮（`.num-highlight`）+ 股票代码等宽字体 + 状态色（蓝 active / 绿 done / 主蓝 hover）；3 列主题 grid + 2 列股票 grid；无独立图表组件，密度靠排版拉满。

## 八、奇门遁甲

- **排盘**：转盘奇门通行口径（干支 / 节气用历法库确定性计算）= 真数据。
- **解盘**：盘面结构化后交模型生成，页面标「AI 解盘 · 仅供参考」；历史记录落库。
- **UI**：问题类型 / 判断目标 / 事情摘要 / 当前阶段表单；解盘档位（标准 / 深入 / 专家）；九宫盘面（天地人盘 + 中宫寄宫）；历法明细（公历 / 农历 / 节气 / 真太阳时 / 年月日时柱 / 旬首）；结果区（一句话 → 核心结论 → 关键信号 → 可操作建议 → 风险）。
- 原版按点数计费（同步 1 / 标准 10 / 深入 20 / 专家 30）——属商业化排除项。

## 九、数据底座

- **全部自建 API**：`aiwuchuan.com/api/*`（nginx / Ubuntu），前端零直连东财 / 腾讯等第三方。
- **K 线端点名 `tdx`**：通达信数据源（自建 pytdx 类网关）。
- **数据策略**：通达信源 + 每日收盘后预计算入库 + 自建 API。
- **关键端点**：
  - 行情类：`/api/tdx-kline`（日 / 分钟，前复权 qfq / 后复权 hfq / 不复权）、`/api/review-stats`（复盘统计）、`/api/index-changes`（12 指数）、`/api/quote` · `/api/quotes`、`/api/search-stock` · `/api/stock-meta`
  - 板块 / 概念：`/api/sector-data` · `/api/concept-data`、`/api/sector-panorama*`（3 个）
  - 题材：`/api/theme-heat/pool·files·summary·theme-detail·realtime-quotes`
  - 选股：`/api/field-registry` · `/api/screen-stocks` · `/api/macd-columns`、`/api/candidate-pools`（GET/POST）· `/api/qf/forward-returns`、`/api/strategies/{id}` · `/api/strategies/{id}/vote`
  - 评估 / 产业链：`/api/stock-eval-matrix*` · `/api/industry-chain-report`
  - 自选：`/api/watchlist/*`
  - 人气：`/api/popularity-rank-series`
- **`/api/review-stats` 日频表字段（每天一条）**：沪深成交额（万亿元）、涨停 / 跌停家数、三 / 四 / 五板及以上 + 最高板、全市场下跌家数、低于 5 日线 / 低于 3 日线家数、高于 5 日线占比（整体 / 微盘 / 中盘 / 大盘）。两张图（成交额柱线、5 日线占比四线）+ 顶四卡全部由这张表驱动。
- **AI 接口**：全部走自建后端 `/api/ai-agent/*`；前端只带控制参数（`llm_mode` 快速分析 / 深度思考=`推理强度 high`、`llm_model_variant` pro / 标准、`search_enabled`、响应深度提示），上游模型名不在前端。
- **实时搜索**：回答带引用来源条，按域名匹配 11 家媒体（东方财富 / 同花顺 / 搜狐 / 21 财经 / 财联社 / 证券时报 / 第一财经 / 巨潮资讯 / 新浪财经 / 金融界 / 中证网）；`/api/ai-agent/data-sources` 数据源登记端点（timeout 120s，会探测各源）。

## 十二、扒取边界（逆向未覆盖，不杜撰）

- 12 个 Prompt 模板的完整正文（100% 在服务端，前端只弹字段收集 dialog）。
- 5 个 horizon 枚举值的 regex 检测规则（在 `resolveTradingHorizonForInput` 实现内，位置未知）。
- 完整 API 路径字面量（被 minified 成别名符号）。
- 完整路由表（在独立 app bundle，未下载）。
- CSS 未逐条穷举，只提取关键 token。
- 截图原图（用户提供的是压缩版本）。
- 图片上传的具体 endpoint（不在主 bundle）。
- `yr` 数组（action 选项，含 buy / sell / absorb / trade_t）定义位置。
