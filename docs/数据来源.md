# 数据来源说明（2026-10-24 同步版）

> 原则：缺了就写「未取到」，不编、不拿 0 冒充。所有来源都是公开接口或你自己配置的服务，
> 仓库里不放任何 Key、Token、密码。`.env` 不入库，照 `.env.example` 自己填。

## 二、新闻接口：新闻筛选页到底读什么

入口：量化条件选股第三个子页，路由 `#/newsfilter`，接口 `GET /api/news/filter`。

- **唯一来源：财联社电报**。公开电报（非 VIP），接口 `GET /v1/roll/get_roll_list` + 签名，
  拉回来先落库 `cls_telegraph`（字段：`id / ctime / sh_time / title / content / subjects / stock_list / created_at`），
  筛选页只读库、不直接爬。
- **留存目前约一周**（库里最早约 2026-10-18）。`days` 参数最大 30，但超过库里有的也只能返回库里有的，
  接口会如实标 `truncated`，不要以为 30 天就真有 30 天。
- **分类是规则版 v1，不是语义模型**：只看标题（标题空时退回正文前 120 字），9 个口子 + 未分类：
  政策制度 / 突发事件 / 产品技术 / 行业数据 / 机构观点 / 负面风险 / 订单中标 / 业绩预告 / 公司事件。
  优先级：负面风险 > 澄清否认（直接未分类）> 订单中标 > 业绩预告 > 突发事件 > 政策制度 > 行业数据 > 产品技术 > 机构观点 > 公司事件。
- **只展示，不接选股、不进 AI 优选、不产买卖信号**。这是 v1 的硬边界。
- **已知会漏**：关键词必漏（例：花旗证券获批标题不在「证券公司 / 券商 + 设立」模式里；
  长川科技预增标题不含「预增」，靠跨词正则才补上）。规则版只保证「分进去的基本是对的」，
  不保证「全分进去」；漏网的先落在未分类里，后续语义分类再补。
- **订单口子双条件**：动作词（中标 / 签约 / 签订 / 签署 / 获得订单 / 拿下订单）+ 金额（`x 亿 / 万元`），
  且排除 MLF / 央行 / 国债 / 地方债 / 能源保供 / 在手订单充足 / 在手订单饱满等。
  澄清 / 否认类（尚无 / 澄清 / 否认）直接归未分类。

## 三、因子：⚠ 三角形不是坏了

多条件量化模型页（`src/components/desk/pages/ScreenerWorkbench.tsx`）的条件 chip 有两种标记，
页面顶部图例已经写了，这里再写一遍，免得再以为是报错：

- **⚠ 黄色三角形 = 「反转因子」，不是故障、不是报错、不是数据坏了。**
  意思是：这个因子在历史上是**反着走**的——数值越高，之后几天反而越容易跌。
  命中它更接近「该回避」，不是「该买入」。点它加入条件时，系统是按反向理解的，
  不要把它当成正向买入信号去用。
  技术口径：`data/factor-truth.json` 里 `direction = "negative"` 的因子（由 `rankIc` 符号定，
  来源是 `factor_test` 表同 key 最新一条；2026-10-23 版共 117 个 key，77 个 negative、0 个 positive、40 个 unknown，
  只有 2 个通过检验）。`data/factor-verified.json` 是已核实的真源，不要和 `factor-verify-report*.json`（批量接口存盘件，已忽略）混用。
- **虚线边框 = 「没通过历史检验」**：历史上看不出稳定效果，别把它当买入理由。
- **灰色 = 「字段待本地实现」**：筛选时会自动剔除，不是你操作错了。
- 顶部另一条 ⚠（「本页只做历史数据分析与条件筛选，不替你下单、也不保证赚钱」）是风险提示，
  不是系统错误。

档位 × 反转事实（档位切换条弹层里的数字）来自 `data/regime-reversal.json`，
由本地前复权粮仓算出（`src/lib/quant/strategy/regime-reversal.ts`，只读本地文件、不发上游请求；
文件缺失就返回 null，页面如实说「还没跑出来」，不编数字）。

## 四、2026-10-15 之后新增的功能（本次同步带上来的）

- **新闻筛选页**：见第二节，`#/newsfilter`，`GET /api/news/filter`。
- **AI 优选逐只评估**：以前是整池拼一个大 prompt 一次调用，容易撞 120 秒超时；
  现在是一只一调、3 路并发，`score >= 60` 入选、最多 10 只，单只失败只丢那只。
  代码：`src/lib/quant/strategy/ai-pick-generate.ts`（`evaluateCandidatesIndividually`）。
- **排雷盖章（只盖章、不拦截）**：每只入选股出厂带章，写进版本文件。
  温度（`pick-heat-core.ts`：当日涨幅 ≥7% / 20 日涨幅 ≥20% / RSI14 ≥60，三项里热的个数）+
  位置（`pick-position-core.ts`：档位 × 位置格）+
  风险标签（`pick-risk-tags-core.ts`：A 放量冲高回落、B 大户派发·散户接盘、C 催化落在买入日、D 薄流动性）。
  盖章口径：温度 ≥2 热或确认 A / B / C = 不合格；温度 1 热 / D / 位置红格 = 注意；疑似与灰格只备忘。
  **盖了「不合格」不是不许买，是提醒你下手前多看一眼。剔除拦截未开。**
  B 标签 2026-10-24 起加了量级门槛：符号达线只是「疑似」，还须大户净卖绝对值 ≥0.1 亿且占成交 ≥3% 才算确认。
- **影子版策略（纯机械对照组）**：与正式版同表（`strategy_pick`，`source='shadow'`、`strategyId=-2`），
  上证 MA20 判档；池子是质量过滤后当日成交额前 300；S2 震荡且均线向下 `ret20 ≤ -30%` 取 10
  （均线向上强制空仓）；S3 弱势 `ret20 ≤ -20%` 取 10；**S1 强势已删除，强势日记空仓行**；
  持有分 h1 / h5 / h20 三档回填（每档扣 0.41%，bench = 上证同期），主考核 h20。
  代码：`src/lib/quant/strategy/shadow-core.ts`、`shadow-collect.ts`，接口 `POST /api/quant/shadow`。
  影子版不排雷（质量过滤除外），不喂模型，不替换正式版。
- **战绩四档台账**：AI 优选每批每只除 T+1 外补记 T+3 / T+5 / T+20（买入统一 D+1 开盘、每档扣 0.41% 一次），
  验证期仍以 T+1 为主口径。

## 五、这个仓库不包含什么（克隆下来要自己补）

- `.env`（Key、Token、网关地址）：不入库，照 `.env.example` 填你自己的。
- 数据库：`prisma/db/custom.db`、`prisma/prisma/db/custom.db`、`data/*.db`、AI 优选版本文件、
  价格快照、K 线缓存、日报 PDF 等运行时产物：不入库，跑起来后自己生成。
- 通达信网关、Longbridge MCP、你自己的模型网关：都是外部服务，仓库里只有调用代码，没有服务本身。
- 2026-07-06 起主板 ST / *ST 涨跌幅由 ±5% 改为 ±10%，历史回测里「ST ±5% 价格指纹」只适用于此前的数据，
  之后不可用；`stock_daily_bar` 的 `name` 是 2026-10-16 快照回填全历史的，不是时点名，
  不要拿它做历史 ST / 退市回溯。
