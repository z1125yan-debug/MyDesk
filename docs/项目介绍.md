# 项目介绍

## 这是什么

**kairotrend-p1**（界面叫 MyDesk / 我的桌面）是一个跑在云 VM 上的**个人量化交易工作台**，是个 Next.js 网页应用。本质是把「行情数据 + AI 模型」捏成一个**能自己选股、出日报、追战绩的桌面**。平时在浏览器打开的那个站就是它。

- 行情数据由服务端直连公开接口获取（腾讯 / 东方财富 / 通达信网关）。
- AI 分析调用 `.env` 里配置的模型接口（当前走本地 Agent2API 中转，笔记本常开即通）。
- 自选 / 追踪 / 历史 / 对话等数据全部存在服务端 SQLite（`prisma/db/custom.db`）。
- 服务端内置调度器，每个交易日北京时间 15:20 之后自动跑当日收盘任务链并生成日报。

> 私有项目，仅供个人学习与技术研究使用。AI 输出由第三方模型生成，仅供参考，**不构成任何投资建议**。

## 有哪些功能（按菜单排）

1. **总览 / 首页**
   自选行情卡片、刷新倒计时、常用入口；首页信号提速、主力净额同源展示。

2. **数据看板**
   板块资金流向榜（实时 / 历史 / 行业 / 概念 / 地域 × 流入 / 流出）、行点击联动明细、资金气泡图。

3. **AI 选股 / 筛选器**
   按「条件墙」筛股票，入选原因显示中文标签；进入页面自动筛选带时序守卫（防止旧响应晚到覆盖用户新结果）；支持选「上一交易日」收盘数据。

4. **AI 优选（AI交易员）**
   接 LLM 工具调用，定时输出优选标的 + 战绩层；手动补跑入口可补当日任务。

5. **涨跌幅分布**
   全 A 的 10 档涨跌幅直方图（替代原来只有涨停 / 跌停两根柱的简陋对比）。

6. **主题热度榜**
   主题热度排名，带新闻窗口与资金口径标注。

7. **战绩页**
   票级台账、次日回填；收益按「扣费后 + 样本外」口径统计。

8. **条件 / 因子**
   因子库（含历史反向标注）；档位强 / 震 / 弱三态切换条上屏。

9. **预测榜 / 行业榜**
   预测排名、行业排名，附日期与口径说明。

10. **AI 分析 / 智能助手**
    K 线图 + 算法支撑 / 阻力 / 趋势通道，按「结构 / 关键位 / 思路 / 风险」的分析师风格输出，一键加入追踪；多会话 AI 对话。

11. **交易日 / 节假日闸**
    交易日最后真值做缓存，休市日不把旧数据冒充实时。

12. **收盘自动调度**
    每个交易日 15:20 后自动跑：`radar → events → breadth → review → roster → sectorsnap → dailysnap → dailybars → picksym → pickfill → aipick`，并生成当日日报。每次执行写 `task_run` 表，按真实记录展示「跑没跑 / 何时跑 / 为何失败」。

13. **量化实验室 / 产业链 / 微信机器人**
    实验性模块（量化实验、产业链联动、企业微信 AI 机器人推送）。

## 技术栈

| 层 | 选型 |
| --- | --- |
| 前端 | Next.js（App Router）· React · TypeScript |
| UI | Tailwind CSS · shadcn/Radix · ECharts |
| 数据 | Prisma · SQLite（`prisma/db/custom.db`） |
| 行情源 | 腾讯 `qt.gtimg.cn` · 东方财富 · 通达信 `eltdx` HTTP 网关 |
| AI | `.env` 配置的 OpenAI 兼容接口（当前经 Agent2API 中转） |
| 协议 | MCP（模型上下文协议）服务器管理与工具调用 |
