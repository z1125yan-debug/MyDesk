# 方向概率预测（第二阶段）放开条件方案

> 本文档只定义「何时 / 如何放开类型 B 方向概率（次日 / 收盘涨跌概率）」的三条硬条件，不写微信推送（见 `wechat-ai-bot-plan.md`，另案处理）。

## 0. 背景与定位

- **当前红线**：系统禁止模型输出「明天上涨概率 80%」类前向涨跌判断。实现位置：`src/lib/quant/event-interpret-core.ts` §九，落库前正则剥离；`worklog.md` §九 同记。
- **现状能力**：
  - **类型 A（阶段方向：主升 / 退潮 / 见顶）已具备**：`src/lib/quant/screener/top-pressure-core.ts` 的 0–100 压力分 + 70/50/30 档位带（R20b 落地）。
  - **类型 B（次日 / 收盘方向概率）当前为禁区**：`src/lib/quant/factors/probability.ts`（294 行，历史条件概率引擎）仅 110 天数据，多数形态样本 <30，标「样本不足」。
- **本方案定位**：当用户决定放开类型 B 时，**必须同时满足以下三条硬条件**；否则一律走「历史条件胜率」表述，不输出方向概率。

## 1. 三条放开条件（必选项，缺一不可）

### 条件一：必附真基准率（true base rate）
- 任何方向判断必须引用**真实历史样本**，格式固定为：
  `条件 X → N 笔样本，1/5/20 日 Y% 同向`。
- 数据来源：直接查 `probability.ts` 的 `historical_probability` 真库，**不许模型凭记忆编百分数**。
- 样本门槛：`N < 30` → 强制输出「样本不足」，**不给数字**（进 `missing[]`，不进答案主体）。
- 红线等价：取不到基准率就标 `missing[]`，模型禁止自行估算。

### 条件二：必附置信区间（confidence interval）
- 区间宽度**绑定样本量**（建议 Wilson 区间）：`N` 小 → 区间宽；`N` 大 → 区间窄。
- 展示格式：`收跌概率 62% [95%CI 44–78]（N=34）`。
- `N` 低于阈值 → 输出「无法给出可靠区间」，不显示点估计。
- 目的：让概率的「可信度」可见，防止把 62% 当成确定结论。

### 条件三：必附证伪条件（falsification）
- 每条方向判断**自动写**「什么情况出现说明该降级 / 证伪」，借用白毛（Serenity）证据阶梯的证伪纪律。
- 示例：`若次日未跌且宽度未继续恶化 → 该见顶信号降级`。
- 与判断**一同留档**，供 Brier 回测自动验证。

## 2. 放开前的门槛（gate，未达不放开）

- **样本积累**：新增每日留档（宽度快照 + 风险等级 + 次日涨跌），攒 **3–6 个月**自产数据。「今天这种下杀」需在训练集里重复出现多次、带标注结果，才能训出预警（物理限制，非加代码可绕过）。
- **压力分刻度重校**：70/50/30 档位带与六条锚点目前是人工拍定，需用留档数据**回标**。R20b 工作日志记「至少两周才谈回测」，实际建议更长（覆盖多种市况）。
- **Brier 回测流水线**：每条判断 N 天后自动判对错、算校准分，上线后才算「可放开」。

## 5. 验收标准

放开后任取一个历史日回放：
1. 输出同时含 **[基准率, 置信区间, 证伪条件]** 三段；
2. `N < 30` 的日子正确**拒绝**输出数字、标「样本不足」；
3. `brier_verify` 表能对每条判断自动回填对错与校准分。
